# بيانات المشروع

الفواتير والصور وملفات XML والمرفقات ونتائج المعالجة التفصيلية مستبعدة من Git. استخدم داخل هذا المجلد عينات مصطنعة أو بيانات حصلت على تصريح صريح لمعالجتها، ولا ترفع أي بيانات مالية أو شخصية حقيقية إلى المستودع العام.

تقارير القياس المجمعة الخالية من المستندات الأصلية موجودة في `06_Testing_Evaluation/Results`.
