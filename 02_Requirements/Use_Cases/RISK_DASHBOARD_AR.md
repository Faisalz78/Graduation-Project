# كشف التجزئة ودرجة المخاطر واللوحة المالية

الإصدار `0.10.0` يضيف أولوية مراجعة مفسرة ولوحة للمراجعين فوق الفحوص المالية الموجودة. لا تتخذ الدرجة قرارًا بدل مدير المشروع أو المالية، ولا تصف الاشتباه بأنه احتيال مثبت.

## كشف تجزئة الفواتير

- يعمل على الفاتورة الأصلية التي اكتمل فيها المورد والمشروع والتاريخ والعملة والإجمالي.
- يجمع الفواتير الأصلية الأخرى المرسلة للمراجعة أو المعتمدة للمورد والمشروع والعملة نفسها خلال سبعة أيام قبل تاريخ المستند الحالي وبعده.
- يقرأ أقل حد مسجل لمدير مشروع نشط مكلف بالمشروع والعملة.
- يصدر WARNING عندما توجد فاتورتان على الأقل، وتكون كل فاتورة منفردة ضمن الحد، بينما يتجاوز مجموع المجموعة الحد.
- يعرض قيمة المستند ومجموع المجموعة والحد وعدد المستندات والنافذة الزمنية. لا يعرض رقم الفاتورة الأخرى أو صاحبها.
- عدم اكتمال الحقول أو غياب حد للمشروع يعطي NOT_CHECKED، والإشعار الدائن أو المدين خارج هذا الفحص.

هذه قاعدة تنبيه قابلة للفهم. قد تكون المجموعة سليمة بسبب دفعات أو تسليمات مستقلة، ولذلك يحتاج المراجع إلى الأصل وأمر الشراء والاستلام قبل القرار.

## درجة أولوية المخاطر

تجمع الدرجة الفحوص التي حالتها WARNING فقط، ثم تقف عند 100. ترتيب العوامل في الواجهة يبدأ بالأعلى وزنًا.

| العامل | الوزن |
|---|---:|
| تطابق الملف الأصلي | 25 |
| تجزئة الفواتير حول الحد | 25 |
| تكرار الهوية المالية | 20 |
| التكرار التقريبي | 20 |
| شذوذ السعر التاريخي | 15 |
| ربط الإشعار وصافي الأصل | 15 |
| بنود أمر الشراء أو الاستلام | 12 لكل فحص |
| التحقق الداخلي من المورد | 10 |
| اختلاف الإجمالي المستحق | 10 |
| اختلاف الضريبة أو المصدر المنظم أو رأس أمر الشراء | 8 لكل فحص |
| اختلاف الصافي | 6 |

- LOW من 0 إلى 19، وMEDIUM من 20 إلى 49، وHIGH من 50 إلى 100.
- موثوقية التغطية LOW إذا اكتمل أقل من ستة فحوص، وMEDIUM من ستة إلى تسعة، وHIGH من عشرة فحوص فأكثر.
- الدرجة الصفرية مع تغطية منخفضة لا تعني أن المستند سليم؛ تعرض الواجهة مستوى التغطية دائمًا.
- تحفظ الدرجة والعوامل ضمن `audit_snapshot` في سجل قرار المراجعة. نسخة السياسة هي `explainable-review-priority-v1`.

## اللوحة المالية

- مدير المشروع يرى المشروعات التي يديرها، ومدير المالية يرى المشروعات النشطة داخل شركته. الموظف لا يصل إلى اللوحة أو API الخاص بها.
- العملة مرشح إلزامي مستقل؛ لا تجمع اللوحة عملات مختلفة ولا تنفذ تحويلًا.
- صافي المعتمد يساوي الفواتير الأصلية والإشعارات المدينة المعتمدة ناقص الإشعارات الدائنة المعتمدة.
- صافي قيد المراجعة يستخدم التعريف نفسه لحالتي مراجعة المشروع والمالية. لا تدعي اللوحة أن الرقم مدفوع أو مقيد محاسبيًا.
- تعرض اللوحة أعداد الحالات، واتجاه صافي المعتمد لستة أشهر، وتجميع المشروع والمورد، والاستثناءات المفتوحة مرتبة حسب درجة المخاطر.
- كل استثناء رابط إلى المستند ودليله وإجراءات المراجع. تستخدم القائمة لقطة التدقيق المحفوظة وتعيد فحص التجزئة الحالي بدل تشغيل OCR والتحليلات الثقيلة لكل فتح للوحة.

## حدود الإصدار

لا توجد ميزانية مشروع مسجلة بعد، ولذلك لا تعرض اللوحة متبقي الميزانية أو انحرافها. لا تنفذ مقارنة الموردين حسب المنطقة، أو تصنيف البنود إلى فئات المشروع، أو تنبيهات خارج التطبيق، أو تقرير PDF/Excel. تحتاج أوزان المخاطر ونافذة التجزئة إلى تقييم على بيانات مستقلة مصرح بها قبل اعتبارها معايرة تشغيلية.
