# الذكاء المالي

هذا المجلد مخصص لتجارب النماذج ودفاتر التقييم ومقاييس البيانات التي قد تضاف بعد توفر مجموعة فواتير واقعية مصرح بها. لا يحتوي تشغيل الإصدار `0.10.0` على نموذج متعلم أو ملف أوزان؛ تعمل درجة المخاطر الحالية بقواعد وأوزان مفسرة داخل FastAPI.

قواعد تحليل السعر والتكرار التقريبي التشغيلية موجودة في `backend/app/services/financial_intelligence.py` لأن FastAPI هو مصدر قواعد العمل والصلاحيات. تستخدم القواعد بيانات PostgreSQL المؤكدة، وتعيد أسبابًا ودرجات قابلة للاختبار، وتحفظ لقطتها مع قرار المراجع.

[المواصفات](../../../02_Requirements/Use_Cases/PRICE_AND_DUPLICATE_INTELLIGENCE_AR.md) و[نتائج الاختبار](../../../06_Testing_Evaluation/Results/PRICE_DUPLICATE_INTELLIGENCE_RESULTS_AR.md) هما المرجع الحالي للحدود والقياس.
