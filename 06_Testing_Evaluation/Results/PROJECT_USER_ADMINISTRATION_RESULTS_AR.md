# نتائج إدارة المشاريع والمستخدمين — 0.13.0

تاريخ التحقق: 13 سبتمبر 2026.

## ما يعمل

- أضاف الترحيل `0010_project_user_administration` أرقام النسخ وتوقيتات التعديل وتفرد رمز المشروع وسجل إدارة محميًا كإضافة فقط.
- يدير مدير المالية الحسابات والأدوار والحالات وكلمات المرور المؤقتة والمشاريع والعضويات من صفحة «إدارة النظام».
- يشتق FastAPI صلاحية العضوية من دور الحساب ويتحقق من الشركة والحالة عند كل كتابة.
- تمنع الحواجز فقد مسودة الموظف أو ترك مراجعة بلا مدير أو تعطيل مشروع مرتبط بسجلات مالية.
- إعادة كلمة المرور تلغي الجلسات السابقة ولا تسجل السر، والتعارض يعيد 409 باستخدام `revision`.

## التحقق

نجح 175 اختبار FastAPI على قاعدة PostgreSQL المخصصة للاختبار، ومنها سبعة اختبارات جديدة للنطاق والإنشاء والتجزئة وسرية السجل وتغيير الأدوار والتزامن وإبطال الجلسات والعضويات وحواجز المهام المفتوحة وحماية سجل الإدارة. نجح Ruff وتنسيق Python وتطابق مخطط Alembic.

نجح بناء Next.js وفحص TypeScript وPrettier. نجح سيناريو Playwright الجديد في إنشاء حساب ومشروع وربط الموظف ومدير المشروع وإعادة كلمة المرور، ثم الدخول بالحساب الجديد ورؤية مشروعه مع غياب رابط الإدارة. راجع السيناريو العرض 1365×900 والعرض الضيق 390×844 دون تمرير أفقي. بعد دمجه أصبحت الحزمة 23 سيناريو متصفح.

## حدود النتيجة

بيانات السيناريو مصطنعة وتبقى في قاعدة التطوير كي لا تستخدم الاختبارات حذفًا عامًا. لا توجد دعوات بريد أو فرض تغيير الكلمة عند أول دخول أو حذف نهائي. لم يختبر التشغيل المتزامن على عدة خوادم أو نشر خارجي، وتبقى تلك ضمن مرحلة التثبيت والنشر.
