# نتائج تطبيق الجوال — 0.11.0

تاريخ التنفيذ: 12 سبتمبر 2026.

## ما تم التحقق منه

| الفحص | النتيجة |
|---|---|
| `npm run typecheck` داخل `04_Source_Code/mobile` | ناجح دون أخطاء TypeScript. |
| `npx expo-doctor` | 21 من 21 فحصًا ناجحًا. |
| `npm run build:android-bundle` | نجح Metro وبنى حزمة Android من 594 وحدة بحجم يقارب 1.5 MB. |
| معاينة Expo Web | ظهرت شاشة الدخول العربية وحقولها وحالاتها دون خطأ تشغيل بعد إضافة مسار تخزين خاص بالمعاينة. |
| اختبارات `test_mobile_auth.py` مع اختبارات الهوية والرفع الأساسية | 40 اختبار خادم ناجحًا، منها أربعة جديدة خاصة بالجوال. |

بعد الاختبار المركز نجح التحقق الشامل: 163 اختبار FastAPI على PostgreSQL المخصص للاختبار، و21 سيناريو Playwright للويب، و22 اختبار وحدة الاستخراج، وفحص Alembic وRuff و`pip check`، وبناء Next.js. لم يتغير مخطط قاعدة البيانات؛ آخر ترحيل هو `0008_governance_documents`.

## تغطية اختبارات الجوال الأمنية

- دخول ناجح يعيد Bearer Token ولا يضبط Cookie.
- التوكن يقرأ الجلسة والمشاريع ضمن النطاق نفسه.
- موظف موثق بالتوكن يرفع صورة صحيحة دون Origin أو CSRF وينشئ مسودة خاصة.
- تسجيل الخروج يبطل الجلسة، ويرفض الخادم استخدامها بعد ذلك.
- توكن تالف يعيد 401 حتى إذا وجدت Cookie ويب صالحة.
- كلمة مرور خاطئة لا تعيد رمز دخول.

## الحدود

بناء حزمة Expo لا يساوي اختبار APK موقع أو تجربة جهاز فعلي. لم تتوفر في جلسة التنفيذ أداة Android Emulator أو جهاز iOS لاختبار منتقي الملفات وSecureStore وسلوك الشبكة الأصلي. توجد عشر ملاحظات `moderate` من `npm audit` داخل سلسلة أدوات Expo الحالية، من دون ملاحظات عالية أو حرجة؛ يقترح npm إصلاحًا يخفض Expo إلى إصدار قديم وغير متوافق، لذلك لم يطبق. يجب إعادة تدقيقها عند صدور تحديث متوافق لـSDK 57 وقبل النشر.

تقتصر النسخة على الدخول والقائمة والتفاصيل والرفع والمتابعة. تعديل بيانات الفاتورة ومراجعة الاستخراج وإثبات الاستلام والرد والموافقات من الجوال ما زالت ضمن التوسعة التالية.
